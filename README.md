# ⚡ AI Builder Pro

**AI Builder Pro** — это мощный и интуитивно понятный веб-инструмент, который превращает ваши текстовые запросы или скриншоты в готовый, рабочий HTML/CSS/JS код. 

Проект создан для дизайнеров, разработчиков и всех, кто хочет быстро прототипировать идеи, не тратя часы на написание шаблонного кода.

### 🚀 Основные возможности

* **Генерация по тексту:** Опишите приложение, и AI создаст его с нуля.
* **Генерация по скриншоту (Vision):** Загрузите картинку понравившегося сайта, и нейросеть воссоздаст его дизайн в коде.
* **Живой предпросмотр:** Смотрите, как выглядит ваш код, прямо в браузере, не покидая приложение.
* **Работа с файлами:** Прикрепляйте свои проекты для доработки или анализа.
* **Поддержка разных моделей:** Используйте бесплатные модели через OpenRouter или мощные платные (Claude 3.5, GPT-4o).
* **Локальное сохранение:** История ваших чатов сохраняется в браузере (LocalStorage), обеспечивая конфиденциальность.
* **Адаптивный интерфейс:** Удобно работать как с компьютера, так и с мобильного телефона.

### 🛠️ Технологии
* Чистый HTML5, CSS3 (Flexbox/Grid, CSS-переменные) и нативный JavaScript (ES6+).
* Интеграция с OpenRouter API.
* Никаких сторонних фреймворков — только быстрый и легкий код.
