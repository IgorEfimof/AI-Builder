# ⚡ AI Builder Pro

**AI Builder Pro** — это веб-инструмент, который превращает текстовые запросы или скриншоты в готовый, рабочий HTML/CSS/JS код. 

Проект создан для быстрой разработки прототипов без написания шаблонного кода с нуля.

## 🚀 Основные возможности
- **Генерация по тексту:** Создание интерфейса по подробному описанию.
- **Генерация по скриншоту (Vision):** Воссоздание дизайна по загруженному изображению.
- **Живой предпросмотр:** Мгновенный рендеринг результата прямо в браузере.
- **Работа с файлами:** Прикрепление существующих проектов для доработки или анализа.
- **Гибкость моделей:** Поддержка бесплатных моделей через OpenRouter или мощных платных (Claude 3.5, GPT-4o).
- **Конфиденциальность:** История чатов сохраняется локально (LocalStorage).
- **Адаптивность:** Корректное отображение и работа на ПК и мобильных устройствах.

## ⚙️ Как запустить локально
Проект не требует сборки или установки зависимостей (Node.js и т.д.).
1. Скачайте файлы репозитория (или откройте через GitHub Pages).
2. Откройте файл `index.html` в любом современном браузере.
3. В настройках приложения укажите свой API-ключ (OpenRouter или аналог) и начните работу.

> **Примечание:** Для работы требуется подключение к интернету и ваш собственный API-ключ.

## 🛠️ Технологии
- HTML5, CSS3 (Flexbox/Grid, CSS-переменные)
- Нативный JavaScript (ES6+)
- OpenRouter API
- *Без тяжелых фреймворков: только быстрый, легкий и чистый код.*
